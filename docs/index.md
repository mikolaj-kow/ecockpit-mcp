# ecockpit-mcp

MCP server exposing WAGO e!COCKPIT PLC automation to LLM/AI editors:
build, import, compile, online variable read/write, library curation,
project lifecycle, live-PLC download — as typed, schema-discoverable
tools.

Independent tooling, not affiliated with or endorsed by WAGO GmbH &
Co. KG (see NOTICE). e!COCKPIT is discontinued by WAGO; this project
targets existing installations.
